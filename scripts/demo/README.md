# Demo脚本使用说明

## 📋 概述

这个目录包含用于端到端验证交易系统的演示脚本。

---

## 🚀 快速开始

### 前置条件

1. **IBKR账号准备**

   - 已注册IBKR Paper Trading账号
   - 已下载并安装TWS或IB Gateway
2. **TWS/Gateway配置**

   - 启动TWS或IB Gateway
   - 登录Paper Trading账号
   - 启用API连接：
     - 配置 → API → 启用ActiveX和Socket客户端
     - 端口设置：TWS=7497, Gateway=4002
3. **项目配置**

   - 确保`.env`或`config.yaml`中IBKR配置正确

   ```yaml
   ibkr:
     host: 127.0.0.1
     port: 7497        # TWS端口，Gateway用4002
     client_id: 1
   ```

## ⚠️ 常见问题

### 1. 连接失败

**问题**：`❌ IBKR连接失败`

**解决方案**：

- 检查TWS/Gateway是否已启动
- 确认已登录Paper Trading账号
- 检查端口配置（TWS: 7497, Gateway: 4002）
- 确认已启用API连接

### 2. 数据订阅失败

**问题**：`❌ 订阅失败`

**解决方案**：

- 检查标的代码是否正确
- 确认市场是否开盘
- 检查Paper账号权限

### 3. 下单失败

**问题**：订单被拒绝

**解决方案**：

- 检查账户余额
- 确认标的可交易
- 查看风控拒绝原因

---

## 🕒 交易时间

**美股交易时间（美东时间 EDT）**：

- 盘前交易：04:00 - 09:30
- 正常交易：09:30 - 16:00
- 盘后交易：16:00 - 20:00

**建议测试时间**：

- 盘前/盘后：数据稀疏，适合测试基本功能
- 正常交易时段：数据频繁，适合完整测试

## 🔧 自定义测试

### 修改测试标的

编辑脚本或使用参数：

```bash
python scripts/demo/run_integrated_demo.py --symbol MSFT
```

### 修改运行时长

```bash
python scripts/demo/run_integrated_demo.py --duration 600  # 10分钟
```

### 修改策略参数

编辑 `run_integrated_demo.py` 中的指标周期：

```python
self.sma_fast = SimpleMovingAverage("SMA_FAST", period=5)   # 改为5周期
self.sma_slow = SimpleMovingAverage("SMA_SLOW", period=10)  # 改为10周期
```
