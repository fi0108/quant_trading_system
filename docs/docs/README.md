## 📖 文档使用说明

### 开始开发前
1. 先读 **[权威架构设计](架构设计文档/权威架构设计.md)**，理解整体架构
2. 再读 **[统一开发计划](计划文档/统一开发计划.md)**，了解开发路线

### 开发过程中
- 每周开始前查看本周任务
- 遇到问题参考架构分析文档
- 开发完成后对照验收标准

### 文档更新原则
- 核心文档（⭐标记）：架构或计划重大变更时更新版本号
- 参考文档：按需更新，保持与实际一致
- 归档文档：不再更新
