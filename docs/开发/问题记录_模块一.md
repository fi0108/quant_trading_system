# 模块一开发问题记录

## 问题 #1: ModuleNotFoundError: No module named 'asyncpg'

### 问题描述
执行 `python scripts/sync_historical_data.py` 时报错：
```
ModuleNotFoundError: No module named 'asyncpg'
```

### 根本原因
**Python 多环境/多解释器导致的依赖包不一致问题**

详细原因：
1. 系统中存在多个 Python 解释器（全局安装、虚拟环境、IDE 内置等）
2. 使用 `pip install` 安装包时，安装到了一个 Python 环境
3. 运行脚本时，使用了另一个没有安装该包的 Python 环境
4. Windows 系统中尤其容易出现，因为可能有：
   - 系统全局 Python
   - Anaconda/Miniconda Python
   - VS Code/PyCharm 虚拟环境
   - Git Bash 默认 Python

### 诊断方法
```bash
# 1. 查看当前使用的 Python 解释器
which python
python --version

# 2. 查看包安装位置
pip show asyncpg

# 3. 测试能否导入
python -c "import asyncpg; print('OK')"

# 4. 如果上面成功，但脚本失败，说明脚本使用了不同的 Python
# 查看脚本使用的解释器
python -c "import sys; print(sys.executable)"
```

### 解决方案

#### 方案 1：使用绝对路径运行（推荐）
```bash
# 先确认 Python 解释器位置
which python

# 使用完整路径运行
/c/Users/Administrator/AppData/Local/Programs/Python/Python312/python scripts/sync_historical_data.py --help
```

#### 方案 2：确保当前环境安装了所有依赖
```bash
# 先检查依赖
python scripts/check_module1_dependencies.py

# 自动安装缺失的包
python scripts/check_module1_dependencies.py --install

# 或手动安装
python -m pip install asyncpg==0.29.0 ib_insync==0.9.86 pandas_market_calendars==4.3.3
```

#### 方案 3：使用虚拟环境（最佳实践）
```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows CMD
venv\Scripts\activate.bat

# Windows PowerShell
venv\Scripts\Activate.ps1

# Git Bash
source venv/Scripts/activate

# 安装依赖
pip install -r requirements.txt

# 运行脚本
python scripts/sync_historical_data.py --help
```

#### 方案 4：在 IDE 中配置 Python 解释器
**VS Code:**
1. 按 `Ctrl+Shift+P`
2. 输入 "Python: Select Interpreter"
3. 选择安装了依赖包的 Python 解释器

**PyCharm:**
1. File → Settings → Project → Python Interpreter
2. 选择或添加正确的解释器
3. 确认依赖包已安装

### 预防措施（重要！）

#### 1. 始终使用虚拟环境
```bash
# 项目根目录下创建 .venv 目录
python -m venv .venv

# 添加到 .gitignore
echo ".venv/" >> .gitignore
echo "venv/" >> .gitignore
```

#### 2. 明确指定 Python 解释器
在脚本开头使用 shebang：
```python
#!/usr/bin/env python
# 或
#!/usr/bin/python3
```

#### 3. 使用 `python -m` 方式运行
```bash
# 而不是直接运行脚本
python -m scripts.sync_historical_data --symbols AAPL
```

#### 4. 添加依赖检查到脚本开头
```python
# 在导入其他模块前检查关键依赖
try:
    import asyncpg
    import ib_insync
    import redis
except ImportError as e:
    print(f"Missing dependency: {e}")
    print("Run: pip install asyncpg ib_insync redis")
    sys.exit(1)
```

### 长期解决方案

#### 创建项目启动脚本

**Windows: `start.bat`**
```batch
@echo off
REM Activate virtual environment and run script

IF NOT EXIST .venv (
    echo Creating virtual environment...
    python -m venv .venv
)

call .venv\Scripts\activate.bat

echo Checking dependencies...
python scripts\check_module1_dependencies.py --install

echo.
echo Virtual environment activated. You can now run:
echo   python scripts\sync_historical_data.py --symbols AAPL
echo.

cmd /k
```

**Linux/Mac: `start.sh`**
```bash
#!/bin/bash

# Create virtual environment if not exists
if [ ! -d ".venv" ]; then
    echo "Creating virtual environment..."
    python3 -m venv .venv
fi

# Activate virtual environment
source .venv/bin/activate

# Check dependencies
echo "Checking dependencies..."
python scripts/check_module1_dependencies.py --install

echo ""
echo "Virtual environment activated. You can now run:"
echo "  python scripts/sync_historical_data.py --symbols AAPL"
echo ""

bash
```
