# 个人量化交易系统开发计划 v1.0
## 避免重构的一次性正确开发路线

---

## 开发原则

### 核心理念

**先打地基，再建房子**

1. **架构先行**：前期投入时间做好设计，避免后期推倒重来
2. **模块独立**：每个模块接口明确，内部实现可迭代
3. **测试同步**：开发过程中同步编写测试
4. **文档同步**：代码和文档同步更新

### 避免重构的关键

- ✅ 数据库表结构一次设计到位
- ✅ 核心接口一次定义清楚
- ✅ 配置化而非硬编码
- ✅ 分层清晰，依赖解耦

**指标使用示例**：
```python
class MyStrategy(QCAlgorithm):
    def Initialize(self):
        self.AddEquity("AAPL", Resolution.Daily)
        self.sma20 = self.SMA("AAPL", 20)
        self.sma60 = self.SMA("AAPL", 60)
    
    def OnData(self, slice):
        if not self.sma20.IsReady or not self.sma60.IsReady:
            return
        
        if self.sma20.Current.Value > self.sma60.Current.Value:
            self.MarketOrder("AAPL", 100)
```
