## 数据模块 (data)

### IBKRClient

**路径**: `src/data/ibkr_client.py`

**职责**: IBKR统一客户端接口

**功能**:
- 连接管理（同步/异步）
- 自动重连
- 实时数据订阅
- 历史数据请求

**核心方法**:
```python
def connect(self) -> bool
def disconnect(self)
def is_connected(self) -> bool
def subscribe_realtime_bars(symbol: str, callback: Callable)
async def get_historical_bars(symbol: str, duration: str, bar_size: str) -> List[BarData]
```

**使用示例**:
```python
from data.ibkr_client import IBKRClient

# 创建客户端
client = IBKRClient(host='127.0.0.1', port=7497, client_id=1)

# 连接
client.connect()

# 订阅实时数据
def on_bar(bars, has_new_bar):
    if has_new_bar:
        print(bars[-1])

client.subscribe_realtime_bars('AAPL', callback=on_bar)

# 获取历史数据
bars = await client.get_historical_bars('AAPL', '1 D', '5 mins')
```

**依赖**:
- `common.config` - 配置管理
- `common.logger` - 日志
- `common.models` - 数据模型

**被依赖**:
- `strategy.*` - 策略模块
- `trading.*` - 交易模块
- `monitor.*` - 监控模块

### DataValidator

**路径**: `src/data/validator.py`

**职责**: 数据验证和质量检查

**功能**:
- 验证行情数据质量
- 检测异常数据
- 安全获取字段
- 提供降级策略

**核心方法**:
```python
def validate(self, data: Dict) -> ValidationResult
def safe_get(self, data: Dict, key: str, default: Any) -> Any
def check_price_spike(self, current: float, previous: float) -> bool
```

**使用示例**:
```python
from data.validator import DataValidator

validator = DataValidator(
    price_spike_threshold=0.1,  # 10%价格波动阈值
    required_fields=['close', 'volume']
)

# 验证数据
result = validator.validate(bar_data)
if result.is_valid:
    price = result.data['close']
else:
    print(f"Invalid data: {result.errors}")

# 安全获取
price = validator.safe_get(bar_data, 'close', default=0.0)
```

**依赖**:
- `common.exceptions` - 异常定义

## 策略模块 (strategy)

### QCAlgorithm

**路径**: `src/strategy/qc_algorithm.py`

**职责**: 策略基类（类似QuantConnect风格）

**功能**:
- 策略生命周期管理
- 数据订阅
- 订单执行
- 持仓管理
- 指标管理

**核心方法**:
```python
def Initialize(self)  # 初始化（用户实现）
def OnData(self, data)  # 数据回调（用户实现）
def OnOrderEvent(self, order_event)  # 订单事件（用户实现）

def AddEquity(self, symbol: str, resolution: Resolution)
def MarketOrder(self, symbol: str, quantity: int) -> Order
def Liquidate(self, symbol: str)
def SMA(self, symbol: str, period: int) -> Indicator
```

**使用示例**:
```python
from strategy.qc_algorithm import QCAlgorithm, Resolution

class MyStrategy(QCAlgorithm):
    def Initialize(self):
        self.AddEquity("AAPL", Resolution.Minute)
        self.sma = self.SMA("AAPL", 20)
    
    def OnData(self, data):
        if not self.sma.IsReady:
            return
        
        if data['close'] > self.sma.Value:
            self.MarketOrder("AAPL", 100)
```

**依赖**:
- `data.ibkr_client` - 数据和交易
- `trading.order.manager` - 订单管理
- `trading.position.manager` - 持仓管理

```python
def check_order(self, order: Order, context: Dict) -> RiskCheckResult

```

**使用示例**:
```python
from risk.manager import RiskManager
from risk.models import Order

risk_mgr = RiskManager()

# 添加规则
risk_mgr.add_rule(position_concentration_rule)
risk_mgr.add_rule(order_size_rule)

# 检查订单
order = Order(symbol='AAPL', quantity=100, action='BUY')
result = risk_mgr.check_order(order, context={'portfolio_value': 100000})

if result.passed:
    # 执行订单
    pass
else:
    print(f"Risk rejected: {result.reason}")
```

**依赖**:

### HealthChecker

**路径**: `src/monitor/health_checker.py`

**职责**: 系统健康检查（一次性检查）

**功能**:
- IBKR 连接检查
- 系统资源检查（CPU、内存）
- 订单状态检查
- 持仓状态检查
- 数据库连接检查
- 生成健康报告

**核心方法**:
```python
def check_connection(self) -> Dict
def check_memory(self, threshold_percent=80.0) -> Dict
def check_cpu(self, threshold_percent=80.0, interval=1.0) -> Dict
def check_orders(self) -> Dict
def check_positions(self) -> Dict
def check_database(self) -> Dict
def check_all(self) -> Dict
def print_report(self, report: Dict)
```

**使用示例**:
```python
from monitor.health_checker import HealthChecker

checker = HealthChecker(ibkr_client, order_manager, position_manager)

# 执行所有检查
report = checker.check_all()
checker.print_report(report)

# 单项检查
conn_result = checker.check_connection()
if not conn_result['passed']:
    print(f"Connection failed: {conn_result['message']}")
```

**依赖**:
- `data.ibkr_client` - IBKR客户端
- `trading.order.manager` - 订单管理
- `trading.position.manager` - 持仓管理

**与 SystemMonitor 的区别**:
- **HealthChecker**: 一次性健康检查，适合启动前、定时检查
- **SystemMonitor**: 持续监控，实时告警
