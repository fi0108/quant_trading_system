# 模块一：市场数据接入 - 快速开始

## 🚀 快速启动（推荐）

### Windows 用户
```bash
# 双击运行或在命令行执行
scripts\start_module1.bat
```

### 手动检查依赖
```bash
# 检查依赖
python scripts/check_module1_dependencies.py

# 自动安装缺失的依赖
python scripts/check_module1_dependencies.py --install
```

## 📝 使用方法

### 1. 历史数据同步

#### 默认同步（最近 6 个月）
```bash
python scripts/sync_historical_data.py --symbols AAPL
```

#### 指定日期范围
```bash
python scripts/sync_historical_data.py --symbols AAPL --start-date 2026-01-01 --end-date 2026-06-30
```

#### 多股票同步
```bash
python scripts/sync_historical_data.py --symbols AAPL,TSLA,GOOGL
```

#### 不同粒度
```bash
# 分钟级数据
python scripts/sync_historical_data.py --symbols AAPL --granularity minute

# 小时级数据
python scripts/sync_historical_data.py --symbols AAPL --granularity hour

# 日线数据（默认）
python scripts/sync_historical_data.py --symbols AAPL --granularity daily
```

### 2. 实时数据服务

#### 启动服务
```bash
python src/connection/market_data_service.py --symbols AAPL
```

#### 多股票监控
```bash
python src/connection/market_data_service.py --symbols AAPL,TSLA,GOOGL
```

#### 自定义配置
```bash
python src/connection/market_data_service.py \
  --symbols AAPL \
  --ibkr-port 4001 \
  --db-url postgresql://user:pass@localhost:5432/quant_trading \
  --redis-url redis://localhost:6379/0
```

### 3. 运行测试

#### 核心测试（P0）
```bash
# 前提：实时服务已运行至少 5 分钟
pytest tests/integration/test_market_data_core.py -v -s
```

#### 单独测试
```bash
# PostgreSQL 测试
pytest tests/integration/test_market_data_core.py::test_realtime_data_write_to_pg -v

# Redis 测试
pytest tests/integration/test_market_data_core.py::test_realtime_data_write_to_redis -v
```

## ❌ 常见问题

### 问题 1: ModuleNotFoundError: No module named 'asyncpg'

**原因**：Python 环境不一致，依赖包未安装到当前环境

**解决**：
```bash
# 步骤 1：检查依赖
python scripts/check_module1_dependencies.py

# 步骤 2：自动安装
python scripts/check_module1_dependencies.py --install

# 步骤 3：验证
python -c "import asyncpg; print('OK')"
```

详细说明：[docs/开发/问题记录_模块一.md](docs/开发/问题记录_模块一.md)

### 问题 2: 测试失败 "No recent data found"

**原因**：实时服务未运行或运行时间不足

**解决**：
1. 确保实时服务正在运行
2. 至少运行 5-10 分钟积累数据
3. 确保当前为交易时段（盘前/盘中/盘后）

### 问题 3: Connection refused (IBKR)

**原因**：IBKR Gateway/TWS 未启动或端口错误

**解决**：
1. 启动 IBKR Gateway 或 TWS
2. 确认端口：TWS=7497, Gateway=4001
3. 使用 `--ibkr-port` 参数指定正确端口

### 问题 4: 数据库连接失败

**原因**：PostgreSQL 未启动或连接信息错误

**解决**：
```bash
# 测试连接
psql -U postgres -d quant_trading -c "SELECT 1"

# 修改连接 URL
python scripts/sync_historical_data.py \
  --symbols AAPL \
  --db-url postgresql://postgres:your_password@localhost:5432/quant_trading
```

## ⚙️ 配置文件

```yaml

  host: 127.0.0.1
  port: 7497  # TWS: 7497, Gateway: 4001

database:
  url: postgresql://postgres:your_password@localhost:5432/quant_trading

  url: redis://localhost:6379/0
```
