### 2.4 核心类设计

#### IBKRClient（统一IBKR接口）

**职责**：IBKR连接、数据订阅、订单执行

**关键方法**：
```python
class IBKRClient:
    def connect(self) -> bool
        """连接IBKR"""
    
    def disconnect(self)
        """断开连接"""
    
    def is_connected(self) -> bool
        """检查连接状态"""
    
    def subscribe_realtime_bars(self, symbol: str, callback: Callable)
        """订阅实时数据"""
    
    async def get_historical_bars(self, symbol: str, duration: str, bar_size: str) -> List[BarData]
        """获取历史数据"""
```

**依赖**：
- common.config
- common.logger
- ib_insync

---

#### QCAlgorithm（策略基类）

**职责**：策略生命周期管理、统一API

**关键方法**：
```python
class QCAlgorithm:
    def Initialize(self)
        """初始化（用户实现）"""
    
    def OnData(self, data: Dict)
        """数据回调（用户实现）"""
    
    def OnOrderEvent(self, order_event: OrderEvent)
        """订单事件（用户实现）"""
    
    def AddEquity(self, symbol: str, resolution: Resolution)
        """添加标的"""
    
    def MarketOrder(self, symbol: str, quantity: int) -> Order
        """市价单"""
    
    def SMA(self, symbol: str, period: int) -> Indicator

```

**依赖**：

### 2.5 数据流

#### 实时交易流程

```
1. IBKR推送实时数据
    ↓
2. IBKRClient接收并验证
    ↓
3. DataValidator检查数据质量
    ↓
4. 分发到Strategy.OnData()
    ↓
5. 策略生成交易信号
    ↓
6. RiskManager风控检查
    ↓
7. OrderManager执行订单
    ↓
8. IBKR确认成交
    ↓
9. PositionManager更新持仓
    ↓
10. AlertManager监控告警
```
