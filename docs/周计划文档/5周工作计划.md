关键决策
决策1：参数优化算法选择
选项A：网格搜索（暴力遍历）

优点：简单，保证找到最优解
缺点：参数多时组合爆炸
选项B：随机搜索

优点：速度快，高维空间表现好
缺点：可能错过最优解
选项C：贝叶斯优化

优点：智能搜索，效率高
缺点：实现复杂，调参困难
决策：选择A+B组合

理由

参数空间小（<500组合）用网格搜索：保证最优
参数空间大（>500组合）用随机搜索：快速探索
第一版不用贝叶斯优化：实现成本高，收益不明显
保持简单：够用就好
实现策略


if total_combinations < 500:
    use_grid_search()
else:
    use_random_search(n_samples=500)
决策2：多策略资金分配方式
选项A：固定权重

优点：简单，可预测
缺点：无法适应策略表现变化
选项B：动态权重（根据表现调整）

优点：自适应，优化资金利用
缺点：可能过度拟合近期表现
选项C：Kelly公式

优点：理论最优
缺点：对胜率和盈亏比估计要求高
决策：选择B，动态权重，但有保护

理由

固定权重太死板：表现差的策略持续占用资金
完全动态有风险：短期表现不代表长期
Kelly公式太激进：实盘无法准确估计参数
保护机制

权重调整有上下限：单次最多变化20%
调整频率限制：每周最多调整1次
最小权重保护：任何策略权重不低于10%
人工审核：重大调整需人工确认

dynamic_weight:
  max_change_pct: 0.2  # 单次最多变20%
  min_weight: 0.1      # 最小权重10%
  rebalance_frequency: weekly
  require_approval: true  # 需要人工确认
