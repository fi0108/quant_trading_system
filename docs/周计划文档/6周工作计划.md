收益归因模型


总收益分解：
总收益 = 选股收益 + 择时收益 + 仓位管理收益 + 交互效应

选股收益：个股相对基准的超额收益
择时收益：进出场时机选择的收益
仓位管理收益：仓位调整带来的收益
风险归因模型


Brinson模型：
组合收益 = 基准收益 + 资产配置效应 + 个股选择效应 + 交互效应

资产配置效应 = Σ(Wi - Wbi) × Rbi
个股选择效应 = Σ Wbi × (Ri - Rbi)
交互效应 = Σ(Wi - Wbi) × (Ri - Rbi)

其中：
Wi - 组合中第i个资产权重
Wbi - 基准中第i个资产权重
Ri - 第i个资产收益率
Rbi - 基准中第i个资产收益率

交易成本分解


总交易成本 = 显性成本 + 隐性成本

显性成本：
- 手续费：交易金额 × 手续费率
- 印花税：卖出金额 × 印花税率

隐性成本：
- 买入滑点：实际成交价 - 信号价
- 卖出滑点：信号价 - 实际成交价
- 市场冲击：大单对价格的影响

-- 事件表设计
CREATE TABLE events (
    id SERIAL PRIMARY KEY,
    event_type VARCHAR(50) NOT NULL,  -- news/earnings/announcement
    symbol VARCHAR(20),
    event_time TIMESTAMP NOT NULL,
    title VARCHAR(500),
    content JSONB,  -- 灵活存储不同类型事件的详细信息

);

1. 回测开始前：加载[start, end]时间段的所有事件

3. 回测循环中：
   - 检查当前时间戳是否有待触发事件
   - 如有，触发策略的事件处理函数
   - 策略生成信号后，正常进入交易流程
4. 回测结束后：统计事件驱动的交易

事件时间对齐：
- 分钟级事件：对齐到当前分钟K线
- 日级事件：对齐到当日开盘
- 盘后事件：对齐到次日开盘
