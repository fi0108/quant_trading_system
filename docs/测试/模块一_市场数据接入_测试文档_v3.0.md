# 模块一：市场数据接入 - 测试文档 v3.0

## 1. 测试概述

本文档定义模块一（市场数据接入）的测试案例，覆盖历史数据同步和实时数据服务两大核心功能。

**测试环境要求**：
- IBKR Gateway 或 TWS 已启动并登录
- PostgreSQL 数据库已创建表结构
- Redis 服务已启动
- Python 环境已安装所有依赖

## 2. 核心测试案例（P0 - 最高优先级）

### 2.1 测试案例 1：历史数据同步完整性测试

**测试目标**：验证历史数据能够正确从 IBKR 同步到 PostgreSQL

**前置条件**：
- IBKR Gateway/TWS 已启动并登录
- PostgreSQL 数据库已创建表结构
- 测试股票：AAPL

**测试步骤**：
1. 执行命令：
   ```bash
   python scripts/sync_historical_data.py --symbols AAPL --start-date 2026-01-01 --end-date 2026-06-30 --granularity daily
   ```
2. 等待同步完成
3. 查询数据库验证数据条数：
   ```sql
   SELECT COUNT(*) FROM market_data_daily 
   WHERE symbol='AAPL' 
     AND timestamp >= '2026-01-01' 
     AND timestamp <= '2026-06-30';
   ```
4. 验证数据质量：
   ```sql
   SELECT * FROM market_data_daily 
   WHERE symbol='AAPL' 
   ORDER BY timestamp DESC 
   LIMIT 10;
   ```

**预期结果**：
- ✅ 同步成功，无报错
- ✅ 数据条数约等于实际交易日数量（约 120 条左右）
- ✅ 数据字段完整：`open`, `high`, `low`, `close`, `volume` 均不为 NULL
- ✅ 数据合法性：
  - `high >= low`
  - `high >= open` 且 `high >= close`
  - `low <= open` 且 `low <= close`
  - `volume >= 0`
- ✅ 时间戳为 UTC 格式

**失败处理**：
- 检查日志文件：`logs/market_data.log`
- 确认是否有连接失败或数据验证失败记录

### 2.2 测试案例 3：实时数据写入 PostgreSQL 测试

**测试目标**：验证实时数据能够正确写入 PostgreSQL

**前置条件**：
- IBKR Gateway/TWS 已启动并登录
- **当前为美股交易时段**（盘前 04:00-09:30 ET / 盘中 09:30-16:00 ET / 盘后 16:00-20:00 ET）
- PostgreSQL 和 Redis 已启动

**测试步骤**：
1. 启动实时数据服务：
   ```bash
   python src/connection/market_data_service.py --symbols AAPL --granularity 1min
   ```
2. 等待 2-3 分钟
3. 查询数据库验证最新数据：
   ```sql
   SELECT * FROM market_data_1min 
   WHERE symbol='AAPL' 
   ORDER BY timestamp DESC 
   LIMIT 5;
   ```
4. 验证 session 字段：
   ```sql
   SELECT DISTINCT session FROM market_data_1min 
   WHERE symbol='AAPL' 
     AND timestamp > NOW() - INTERVAL '10 minutes';
   ```

**预期结果**：
- ✅ 数据库中有新数据写入
- ✅ 数据时间戳接近当前时间（UTC）
- ✅ `session` 字段正确标记：
  - 盘前时段：`'pre_market'`
  - 正常交易：`'regular'`
  - 盘后时段：`'after_hours'`
- ✅ 数据合法性验证通过

**失败处理**：
- 确认当前是否为交易时段
- 检查服务日志输出
- 验证 IBKR 数据订阅是否成功

### 2.3 测试案例 4：实时数据写入 Redis 测试

**测试目标**：验证实时数据能够正确写入 Redis 缓存

**前置条件**：
- 实时数据服务正在运行（延续测试案例 3）

**测试步骤**：
1. 连接 Redis：
   ```bash
   redis-cli
   ```
2. 查询缓存数据：
   ```redis
   LRANGE AAPL:latest_bars:1min 0 -1
   ```
3. 验证数据条数：
   ```redis
   LLEN AAPL:latest_bars:1min
   ```
4. 查看最新一条数据：
   ```redis
   LINDEX AAPL:latest_bars:1min 0
   ```

**预期结果**：
- ✅ Redis 中存在 key `AAPL:latest_bars:1min`
- ✅ 数据为 JSON 格式的 K 线列表
- ✅ 数据条数 ≤ 100（最多保留 100 条最新数据）
- ✅ 最新数据在列表头部（index 0）
- ✅ JSON 包含字段：`timestamp`, `open`, `high`, `low`, `close`, `volume`, `session`

**失败处理**：
- 检查 Redis 服务是否正常
- 确认服务配置中 Redis 连接信息正确

### 3.3 测试案例 7：数据验证器测试

**测试目标**：验证非法数据被正确拒绝

**测试类型**：单元测试

**测试步骤**：
创建单元测试文件 `tests/unit/test_data_validator.py`：

```python
import pytest
from src.common.data_validator import DataValidator

def test_negative_price():
    """测试负数价格"""
    bar = {'open': -10, 'high': 150, 'low': 149, 'close': 150, 'volume': 1000}
    is_valid, error = DataValidator.validate_bar(bar)
    assert is_valid == False
    assert "positive" in error.lower()

def test_high_less_than_low():
    """测试 high < low"""
    bar = {'open': 150, 'high': 100, 'low': 120, 'close': 110, 'volume': 1000}
    is_valid, error = DataValidator.validate_bar(bar)
    assert is_valid == False
    assert "high" in error.lower() and "low" in error.lower()

def test_negative_volume():
    """测试负数成交量"""
    bar = {'open': 150, 'high': 151, 'low': 149, 'close': 150, 'volume': -500}
    is_valid, error = DataValidator.validate_bar(bar)
    assert is_valid == False
    assert "volume" in error.lower()

def test_valid_bar():
    """测试合法数据"""
    bar = {'open': 150, 'high': 151, 'low': 149, 'close': 150.5, 'volume': 1000}
    is_valid, error = DataValidator.validate_bar(bar)
    assert is_valid == True
    assert error == ""
```

**预期结果**：
- ✅ 所有非法数据返回 `is_valid=False`
- ✅ 返回准确的错误信息
- ✅ 合法数据返回 `is_valid=True`

**运行测试**：
```bash
pytest tests/unit/test_data_validator.py -v
```

### 4.3 测试案例 9：多粒度数据测试

   ```bash
   # 小时级
   python scripts/sync_historical_data.py --symbols AAPL --start-date 2026-07-01 --end-date 2026-07-31 --granularity hour
   
   # 日级
   python scripts/sync_historical_data.py --symbols AAPL --start-date 2026-07-01 --end-date 2026-07-31 --granularity daily
   
   # 周级
   python scripts/sync_historical_data.py --symbols AAPL --start-date 2026-01-01 --end-date 2026-07-31 --granularity week
   
   # 月级
   python scripts/sync_historical_data.py --symbols AAPL --start-date 2025-01-01 --end-date 2026-07-31 --granularity month
   ```

2. 检查对应数据表：
   ```sql
   SELECT 'market_data_1min' as table_name, COUNT(*) FROM market_data_1min WHERE symbol='AAPL'
   UNION ALL
   SELECT 'market_data_1hour', COUNT(*) FROM market_data_1hour WHERE symbol='AAPL'
   UNION ALL
   SELECT 'market_data_daily', COUNT(*) FROM market_data_daily WHERE symbol='AAPL'
   UNION ALL
   SELECT 'market_data_weekly', COUNT(*) FROM market_data_weekly WHERE symbol='AAPL'
   UNION ALL
   SELECT 'market_data_monthly', COUNT(*) FROM market_data_monthly WHERE symbol='AAPL';
   ```

**预期结果**：
- ✅ 五张表分别有对应粒度的数据
- ✅ 数据条数符合粒度预期：
  - 分钟级：约 6.5 小时/天 × 22 天 × 60 分钟 ≈ 8,580 条
  - 小时级：约 6.5 × 22 ≈ 143 条
  - 日级：约 22 条（7 月交易日）
  - 周级：约 30 条（半年）

为核心测试案例（P0）提供自动化测试脚本：

**文件位置**：`tests/integration/test_market_data_core.py`

```python
import pytest
import time
from datetime import datetime, timedelta
import psycopg2
import redis

@pytest.fixture
def db_connection():
    """PostgreSQL 连接"""

    )
    yield conn
    conn.close()

def redis_client():
    """Redis 连接"""
    r = redis.Redis(host='localhost', port=6379, db=0, decode_responses=True)
    yield r
    r.close()

@pytest.mark.integration
def test_realtime_data_write_to_pg(db_connection):
    """测试案例 3：实时数据写入 PG"""
    cursor = db_connection.cursor()
    
    # 查询最近 5 分钟的数据
    cursor.execute("""
        SELECT COUNT(*), MIN(timestamp), MAX(timestamp) 
        FROM market_data_1min 
        WHERE symbol='AAPL' 
          AND timestamp > NOW() - INTERVAL '5 minutes'
    """)
    count, min_ts, max_ts = cursor.fetchone()
    
    # 断言
    assert count > 0, "No recent data found in PostgreSQL"
    assert max_ts is not None, "No timestamp found"
    
    # 验证 session 字段
    cursor.execute("""
        SELECT DISTINCT session 
        FROM market_data_1min 
        WHERE symbol='AAPL' 
          AND timestamp > NOW() - INTERVAL '5 minutes'
    """)
    sessions = [row[0] for row in cursor.fetchall()]
    assert len(sessions) > 0, "No session data found"
    assert sessions[0] in ['pre_market', 'regular', 'after_hours'], f"Invalid session: {sessions[0]}"
    
    cursor.close()
    print(f"✅ PostgreSQL test passed: {count} bars found, session={sessions[0]}")

@pytest.mark.integration
def test_realtime_data_write_to_redis(redis_client):
    """测试案例 4：实时数据写入 Redis"""
    key = 'AAPL:latest_bars:1min'
    
    # 检查 key 存在
    assert redis_client.exists(key), f"Redis key {key} does not exist"
    
    # 检查数据条数
    length = redis_client.llen(key)
    assert length > 0, "Redis list is empty"
    assert length <= 100, f"Redis list too long: {length}"
    
    # 检查数据格式
    latest_bar = redis_client.lindex(key, 0)
    assert latest_bar is not None, "No data in Redis"

    bar_data = json.loads(latest_bar)
    assert 'timestamp' in bar_data
    assert 'open' in bar_data
    assert 'high' in bar_data
    assert 'low' in bar_data
```
