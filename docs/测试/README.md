## 测试文档必备内容
1. **测试范围与策略**：测试类型划分
2. **测试用例设计**：单元/集成/系统测试用例
3. **真实环境验证**：只读验证方案
4. **异常场景测试**：边界条件、错误处理
5. **性能测试**：并发、稳定性
6. **回归测试清单**：必跑用例列表
7. **测试数据准备**：Mock数据、测试账号

## 测试原则
- ✅ 真实环境验证：数据准确性、连接稳定性、账户查询
- ❌ 真实环境禁止：下单交易、风控测试、异常注入
- 🔄 模拟盘覆盖：所有交易功能必须在模拟盘验证通过

## 关键验收标准
- 代码覆盖率：核心模块 ≥ 80%
- 集成测试：模拟盘24小时稳定运行
- 真实验证：上线前必须完成只读环境验证
- 回归测试：每次发版前必跑完整回归套件
