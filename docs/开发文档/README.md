## 开发文档必备内容
1. **技术架构设计**：模块分层、类结构
2. **核心接口定义**：方法签名、参数类型
3. **数据模型设计**：数据库表、缓存键
4. **关键算法实现**：复杂逻辑的伪代码
5. **错误处理机制**：异常分类、重试策略
6. **配置参数说明**：可配置项、默认值
7. **单元测试设计**：测试用例覆盖
8. **部署运行说明**：启动命令、健康检查

## 开发规范
- 开发前：必须先有对应的产品需求文档
- 开发中：边开发边完善开发文档（接口定义、数据模型）
- 代码审查：对照开发文档检查实现是否偏离设计
- 文档同步：代码重构后及时更新文档
