# 模块一：市场数据接入 - 开发文档 v3.0

## 1. 核心思路

本模块实现两个独立的数据同步程序：

1. **历史数据同步脚本**（`sync_historical_data.py`）：按需执行，同步指定股票的历史数据到 PostgreSQL
2. **实时数据服务**（`market_data_service.py`）：持续运行，订阅实时数据流并写入 Redis + PostgreSQL

### 3.2 数据验证器 (`DataValidator`)

**功能**：验证K线数据的合法性

**核心逻辑**：
```python
class DataValidator:
    @staticmethod
    def validate_bar(bar_data: dict) -> tuple[bool, str]:
        """验证单条K线数据
        
        返回：
            (is_valid, error_message)
        """
        if bar_data['open'] <= 0:
            return False, "open price must be positive"
        if bar_data['high'] < bar_data['low']:
            return False, "high must >= low"
        if bar_data['high'] < max(bar_data['open'], bar_data['close']):
            return False, "high must >= open and close"
        if bar_data['low'] > min(bar_data['open'], bar_data['close']):
            return False, "low must <= open and close"
        if bar_data['volume'] < 0:
            return False, "volume must be non-negative"
        
        return True, ""
```

**文件**：`scripts/sync_historical_data.py`

# 2. 默认时间处理

# 4. 循环处理每只股票

    # 5. 请求历史数据

        symbol=symbol,
        start_date=start_date,
        end_date=end_date,
        bar_size=GRANULARITY_MAP[args.granularity]
    )
    
    # 6. 数据验证

### 4.2 实时数据服务

**文件**：`src/connection/market_data_service.py`

**实现流程**：
```python
class MarketDataService:
    def __init__(self, symbols, granularity='1min'):
        self.symbols = symbols
        self.granularity = granularity
        self.client = IBKRClient()
        self.data_store = DataStore(pg_config, redis_config)
        self.tz_manager = TimezoneManager()
        self.calendar = TradingCalendar()
        self.is_running = False
        
    def start(self):
        """启动服务"""
        self.is_running = True
        self.client.connect()
        
        # 订阅所有股票
        for symbol in self.symbols:
            self.client.subscribe_realtime_bars(
                symbol=symbol,
                bar_size=self.granularity,
                callback=self._on_new_bar
            )
        
        # 进入主循环
        self._main_loop()
    
    def _on_new_bar(self, symbol, bar_data):
        """实时数据回调"""
        # 1. 数据验证
        is_valid, error = DataValidator.validate_bar(bar_data)
        if not is_valid:
            logger.error(f"Invalid bar for {symbol}: {error}")
            return
        
        # 2. 添加session字段
        bar_data['session'] = self.tz_manager.get_current_session()
        
        # 3. 时间转UTC
        bar_data['timestamp'] = self.tz_manager.to_utc(bar_data['timestamp'])
        
        # 4. 写入Redis
        self.data_store.save_bar_to_redis(symbol, bar_data, self.granularity)
        
        # 5. 写入PostgreSQL
        self.data_store.save_bars_to_pg(symbol, [bar_data], self.granularity)
        
        logger.info(f"Saved bar for {symbol} at {bar_data['timestamp']}")
    
    def _main_loop(self):
        """主循环：处理交易时段和休眠"""
        while self.is_running:
            current_session = self.tz_manager.get_current_session()
            
            if current_session == 'closed':
                # 非交易时段，休眠
                logger.info("Market closed, sleeping...")
                time.sleep(300)  # 每5分钟检查一次
            else:
                # 交易时段，保持活跃
                time.sleep(1)
    
    def stop(self):
        """停止服务"""
        self.is_running = False
        self.client.disconnect()

# 主入口
if __name__ == '__main__':
    parser = argparse.ArgumentParser()
    parser.add_argument('--symbols', required=True)
    parser.add_argument('--granularity', default='1min')
    args = parser.parse_args()
    
    symbols = args.symbols.split(',')
    service = MarketDataService(symbols, args.granularity)
    
    try:
        service.start()
    except KeyboardInterrupt:
        service.stop()
```

## 8. 异常处理

### 8.1 连接异常
- IBKR连接失败：重试3次，间隔5秒
- 数据库连接失败：重试3次，间隔10秒
- 网络超时：单次请求超时30秒

### 8.2 数据异常
- 数据验证失败：记录日志，跳过该条数据
- 重复数据：使用 `UNIQUE(symbol, timestamp)` 约束自动忽略

### 8.3 服务异常
- 实时服务意外退出：自动重启（使用systemd或supervisor管理）
- 数据缺口：启动时自动检测并回填

## 9. 测试要点

1. **历史数据同步**：验证指定时间段数据是否完整写入PostgreSQL
2. **实时数据写入**：验证交易时段数据同时写入Redis和PostgreSQL
3. **时区转换**：验证数据库中timestamp为UTC格式
4. **交易时段识别**：验证session字段正确标记（pre_market/regular/after_hours）
5. **数据验证**：验证非法数据被正确拒绝
