# 模块一功能点与测试用例补充报告

## 一、已补充的核心组件

### 1. **IBKRClient 封装类** ✅
- 文件：`src/connection/ibkr_client.py`
- 功能：
  - `get_historical_bars()` - 获取历史K线数据
  - `subscribe_realtime_bars()` - 订阅实时数据流
  - 自动连接管理和错误处理

### 2. **DataStore 统一存储层** ✅
- 文件：`src/connection/storage/data_store.py`
- 功能：
  - 统一接口封装 PostgreSQL 和 Redis
  - `save_bars_to_pg()` - 批量保存到 PG
  - `save_bar_to_redis()` - 单条保存到 Redis
  - `save_bar()` - 同时保存到两个存储

### 3. **历史数据同步脚本** ✅
- 文件：`scripts/sync_historical_data.py`
- 功能：
  - 命令行工具，支持参数：`--symbols`, `--start-date`, `--end-date`, `--granularity`
  - 默认同步 6 个月数据
  - 支持多股票并行同步
  - 支持五种粒度：minute, hour, daily, week, month

### 4. **实时数据服务** ✅
- 文件：`src/connection/market_data_service.py`
- 功能：
  - 常驻服务，持续订阅实时数据
  - 自动添加 session 字段（pre_market/regular/after_hours）
  - 自动时区转换（美东时间 → UTC）
  - 非交易时段自动休眠
  - 数据验证和错误处理

### 5. **数据库表创建脚本** ✅
- 文件：`scripts/create_tables.sql`
- 功能：
  - 创建 5 张表：market_data_1min, market_data_1hour, market_data_daily, market_data_weekly, market_data_monthly
  - 添加索引优化查询性能
  - UNIQUE 约束防止重复数据

### 6. **配置文件** ✅
- 文件：`config/market_data_config.yaml`
- 功能：
  - 集中配置 IBKR、PostgreSQL、Redis 连接参数
  - 数据验证规则配置
  - 日志配置
  - 交易时段配置

### 7. **TimezoneManager.get_current_session()** ✅
- 文件：`src/core/timezone_manager.py`
- 功能：
  - 新增方法返回当前交易时段
  - 返回值：'pre_market' | 'regular' | 'after_hours' | 'closed'

## 五、如何运行测试

### 1. 前置准备
```bash
# 创建数据库表
psql -U postgres -d quant_trading -f scripts/create_tables.sql

# 启动 IBKR Gateway/TWS（确保已登录）

# 启动 Redis
redis-server

# 启动实时数据服务（在另一个终端）
python src/connection/market_data_service.py --symbols AAPL
```

### 2. 运行核心测试（P0）
```bash
# 等待服务运行至少 5 分钟后执行
pytest tests/integration/test_market_data_core.py -v -s

# 只运行 PostgreSQL 测试
pytest tests/integration/test_market_data_core.py::test_realtime_data_write_to_pg -v -s

# 只运行 Redis 测试
pytest tests/integration/test_market_data_core.py::test_realtime_data_write_to_redis -v -s
```

### 3. 手动验证
```bash
# 查看 PostgreSQL 最近数据
python tests/integration/test_market_data_core.py

# 或直接 SQL 查询
psql -U postgres -d quant_trading -c "SELECT * FROM market_data_1min WHERE symbol='AAPL' ORDER BY timestamp DESC LIMIT 5;"

# 查看 Redis 数据
redis-cli
> LRANGE AAPL:latest_bars 0 4
> LLEN AAPL:latest_bars
```

### 4. 历史数据同步测试
```bash
# 同步 AAPL 最近 6 个月（默认）
python scripts/sync_historical_data.py --symbols AAPL

# 同步指定日期范围
python scripts/sync_historical_data.py --symbols AAPL --start-date 2026-01-01 --end-date 2026-06-30

# 验证数据
psql -U postgres -d quant_trading -c "SELECT COUNT(*) FROM market_data_daily WHERE symbol='AAPL';"
```

## 六、测试注意事项

### 核心测试（test_market_data_core.py）要求
1. **必须在交易时段运行**
   - 盘前：04:00-09:30 ET
   - 盘中：09:30-16:00 ET
   - 盘后：16:00-20:00 ET
   - 其他时间服务会休眠，无数据写入

2. **服务需要提前运行**
   - 至少运行 5 分钟以积累足够数据
   - 建议运行 10 分钟以上更稳定

3. **数据库密码配置**
   - 修改测试文件中的数据库密码：`password='your_password'`
   - 或使用环境变量

### 测试失败排查
如果测试失败，按以下顺序检查：

1. **服务是否正常运行**
   ```bash
   # 检查服务日志，应看到类似输出：
   # [AAPL] Saved bar: 2026-08-10T13:35:00+00:00 close=150.25 session=regular
   ```

2. **IBKR 连接是否正常**
   ```bash
   # 日志应显示：
   # Connected to IBKR at 127.0.0.1:7497
   # Subscribing to real-time data...
   ```

3. **数据库/Redis 连接是否正常**
   ```bash
   # PostgreSQL 测试
   psql -U postgres -d quant_trading -c "SELECT 1"
   
   # Redis 测试
   redis-cli ping
   ```

4. **当前是否为交易时段**
   ```python
   from src.core.timezone_manager import TimezoneManager
   tz = TimezoneManager()
   print(tz.get_current_session())  # 应输出 'pre_market'/'regular'/'after_hours'
   ```
